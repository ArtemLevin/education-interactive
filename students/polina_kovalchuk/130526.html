Принцип Дирихле

Когда объектов больше, чем возможных вариантов.

2
Формулировка: если n + 1 объект распределён по n ящикам, то хотя бы в одном ящике окажется не меньше двух объектов.
остатки при делении на m: 0, 1, 2, ..., m − 1
если a = mx + r и b = my + r, то a − b = m(x − y)
Значит, если два числа дают одинаковый остаток при делении на m, то их разность делится на m.
Покажи объяснение

Среди 21 целого числа всегда найдутся два с одинаковым остатком при делении на 20, потому что остатков только 20. Их разность делится на 20.

Мини-вывод: «много чисел + остатки + разность делится» почти всегда означает принцип Дирихле.

Инварианты

Что не меняется при разрешённой операции?

3
Инвариант — величина или свойство, которое сохраняется при каждом разрешённом ходе.
до: a + b
после: |a − b|
если a ≥ b, то (a + b) − (a − b) = 2b
В общем случае сумма уменьшается на 2 · min(a, b), то есть на чётное число. Поэтому чётность всей суммы сохраняется.
Покажи алгоритм
  1. Посчитайте вклад выбранных чисел до операции.
  2. Посчитайте вклад после операции.
  3. Сравните разность: часто сохраняется чётность или остаток.
  4. Сравните начальное и конечное состояние.
Мини-вывод: если последнее число имеет невозможную чётность, значит такой финал невозможен.

Остатки и периодичность

Рекуррентные последовательности удобно смотреть по модулю.

4
Для последовательности Фибоначчи a1 = 1, a2 = 1, an+2 = an+1 + an остатки по модулю 2 повторяются.
an mod 2: 1, 1, 0, 1, 1, 0, ...
период чётности = 3
n ≡ 1 mod 3 → an нечётно
n ≡ 2 mod 3 → an нечётно
n ≡ 0 mod 3 → an чётно
Покажи объяснение

Для a7 + a11 + a18: номера дают остатки 1, 2 и 0 при делении на 3. Значит, чётности: нечётный, нечётный, чётный. Сумма чётна.

Мини-вывод: не обязательно знать большие члены — достаточно знать период остатков.

Разбиение на группы

Сумма группы часто даёт запрет.

5
Если в каждой группе из трёх чисел одно равно сумме двух других, группу можно записать как x, y, x + y.
сумма группы = x + y + (x + y) = 2(x + y)
Сумма каждой такой группы чётна. Значит, сумма всех чисел исходного набора тоже должна быть чётной, если такое разбиение существует.
1 + 2 + ... + 9 = 45
45 — нечётное число, а сумма групп вида x, y, x + y должна быть чётной. Противоречие: разбить числа 1, 2, ..., 9 так нельзя.
Покажи алгоритм
  1. Опишите вид одной группы.
  2. Найдите сумму группы.
  3. Сравните с суммой всех чисел.
  4. Если строите пример, проверьте, что каждое число использовано ровно один раз.
Мини-вывод: один повтор в построении ломает всё разбиение.

Задачи «может ли»

Возможность доказывается одним корректным примером.

6
Если нужно доказать, что ситуация может произойти, достаточно привести один набор, который полностью подходит под условие.
однозначное x → 11x, прирост = 11x − x = 10x
двузначное 10a + b → (a + b) / 2
Пример: исходный набор 1, 1, 19. После преобразования получаем 11, 11, 5.
S1 = 1 + 1 + 19 = 21; S2 = 11 + 11 + 5 = 27; S2 − S1 = 6
Покажи объяснение

Условие выполнено: есть однозначные и двузначное число, цифры только 1, 3, 5, 7, 9, все числа меньше 100, новая сумма больше исходной на 6.

Мини-вывод: один пример доказывает возможность, но не доказывает утверждение «для всех».

Разбор ошибок

Ваш ответ → ошибка → как думать правильно.

!
Неверный ход: «Разбиение чисел 1, ..., 9 найдено: (1, 8, 9), (2, 6, 8), (3, 4, 7)».
Ошибка: число 8 повторяется. Это не разбиение, потому что каждое число исходного набора должно использоваться ровно один раз.
Правильный ответ: числа 1, 2, ..., 9 нельзя разбить на три группы вида x, y, x + y.
1 + 2 + ... + 9 = 45 — нечётно
каждая группа x, y, x + y имеет сумму 2(x + y) — чётно
Покажи правильный алгоритм
  1. Не начинайте с хаотичного подбора, если есть быстрый общий запрет.
  2. Сначала проверьте сумму, чётность или другой инвариант.
  3. Если строите группы, отмечайте использованные числа.
  4. Любой повтор означает, что пример неверен.
Мини-вывод: в задачах на группы проверка «каждое число ровно один раз» обязательна.

Повтори за 30 секунд

Пять быстрых вопросов.

9
1. Почему среди n + 1 целых чисел найдутся два с одинаковым остатком при делении на n?
Ответ

Остатков всего n: 0, 1, ..., n − 1. Чисел больше, значит по принципу Дирихле два попадут в один остаток.

2. Что сохраняется при операции «стереть a и b, записать |a − b|»?
Ответ

Сохраняется чётность суммы всех чисел.

3. При каких номерах члены последовательности Фибоначчи чётны?
Ответ

Чётны те члены, номера которых кратны 3.

4. Почему группа x, y, x + y имеет чётную сумму?
Ответ

x + y + (x + y) = 2(x + y), это чётное число.

Опорные правила

10
Дирихле n + 1 чисел и n остатков → два числа имеют одинаковый остаток
Разность одинаковые остатки при делении на m → разность делится на m

Мини-самопроверка

Выберите ответ: подсветка появится сразу.

11
1. Среди любых 21 целого числа найдутся два, разность которых делится на...
Остатков при делении на 20 ровно 20, а чисел 21. Поэтому верный ответ — 20.
2. Сумма чисел 1 + 2 + ... + 2025 имеет какую чётность?
Сумма равна 2025 · 2026 / 2 = 2025 · 1013, оба множителя нечётны. Сумма нечётная.
3. Если номер члена Фибоначчи кратен 3, то член...
Остатки по модулю 2 идут с периодом 1, 1, 0. При номере, кратном 3, член чётный.
4. Что обязательно проверить в разбиении на группы?
Повторы запрещены: иначе это не разбиение исходного набора.
