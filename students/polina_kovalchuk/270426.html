Задание 19:
прогрессии

Короткая, наглядная и практическая версия чек-листа: формулы, ограничения, делимость, максимум через минимальную сумму и проверка геометрической прогрессии.

Смысл: формула + ограничения + здравый перебор

1. Главная идея

В 19-м задании часто решает не «сложная теория», а точная фиксация ограничений.

натуральность различность делимость чётность минимальная сумма обоснованный перебор
Если члены разные и натуральные: a₁ ≥ 1, d ≥ 1, n ∈ ℕ.
Шаг 1. Записать прогрессию через первый член и разность.
Шаг 2. Подставить условие в формулу суммы или крайнего члена.
Шаг 3. Использовать делимость, чётность, положительность.
Шаг 4. Проверить кандидатов и привести пример или доказать невозможность.

2. Арифметическая прогрессия

Формулы

aₙ = a₁ + (n − 1)d
Sₙ = ((2a₁ + (n − 1)d) / 2) · n
Sₙ / n = (a₁ + aₙ) / 2

Ограничения

  • Если числа натуральные: a₁ ≥ 1.
  • Если числа разные и идут по возрастанию: d ≥ 1.
  • Если Sₙ = M, то n · (2a₁ + (n − 1)d) = 2M.
  • Следовательно, n делит 2M.

3. Минимальная сумма

Чтобы сделать количество членов максимальным, берём самый «дешёвый» вариант:

1 + 2 + ... + n = n(n + 1) / 2

Это нижняя граница суммы для n разных натуральных членов арифметической прогрессии.

Пример. Если Sₙ < 900, решаем n(n+1)/2 < 900. Получаем максимум n = 41.

4. Геометрическая прогрессия

bₙ = b₁ · qⁿ⁻¹
Для 5 членов: b₁ · b₂ · b₃ · b₄ · b₅ = b₃⁵

Если пять натуральных чисел образуют геометрическую прогрессию, их произведение обязано быть пятой степенью натурального числа.

Пример. 1512 = 2³ · 3³ · 7. Это не пятая степень, значит такой прогрессии нет.

5. Закрепление

Задача 1. Даны 4 различных натуральных числа в арифметической прогрессии. Может ли сумма быть равна 18?
Да: 3, 4, 5, 6.
Задача 2. Найдите наибольшее n, если сумма n разных натуральных членов арифметической прогрессии меньше 300.
n = 23, так как 23·24/2 = 276, а 24·25/2 = 300.
Задача 3. Может ли произведение пяти натуральных членов геометрической прогрессии быть равно 1024?
Нет: 1024 = 2¹⁰, показатель 10 не делится на 5.
