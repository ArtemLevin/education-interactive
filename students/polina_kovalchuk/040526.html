Делимость и признаки

Базовые определения

  • Делимость: число a делится на b, если a = b·k, где k — целое число и b ≠ 0.
  • Простое число имеет ровно два натуральных делителя: 1 и само себя.
  • Составное число имеет больше двух натуральных делителей.
  • 1 не является ни простым, ни составным числом.

Признаки делимости

2

Метод «оценка плюс пример»

1. Докажите границу 2. Постройте пример 3. Проверьте условия

Метод нужен в задачах на максимум, минимум, наибольшее или наименьшее значение. Решение считается полным только тогда, когда есть и оценка, и пример, достигающий оценки.

если a > 3b и a, b — целые, то минимально возможно: a = 3b + 1

Типовая оценка дроби

Если a, b, c, d — натуральные, b + d ≠ 0, a > 3b и c > 6d, то:

a + c > 3b + 6d > 3b + 3d = 3(b + d)
значит, (a + c) / (b + d) > 3
Следовательно, равенство (a + c) / (b + d) = 3 невозможно.
Пример с двузначными числами
Если a, b, c, d — двузначные натуральные числа, a > 3b, c > 6d, то минимальные значения:
a = 3b + 1, c = 6d + 1
(a + c) / (b + d) = 3 + (3d + 2) / (b + d)
Чтобы дробь была минимальной, берём b максимально возможным, d минимально возможным:
b = 32, d = 10, a = 97, c = 61
Ответ:
79 / 21
3

НОД и НОК

Определения

  • НОД(a,b) — наибольший общий делитель чисел a и b.
  • НОК(a,b) — наименьшее общее кратное чисел a и b.
a · b = НОД(a,b) · НОК(a,b)

Алгоритм Евклида

Делим большее число на меньшее, затем делитель — на остаток. Последний ненулевой остаток — это НОД.

Пример: 84 и 60

84 = 60·1 + 24
60 = 24·2 + 12
24 = 12·2 + 0

Значит, НОД(84,60) = 12.

НОК(84,60) = 84·60 / 12 = 420

Пары чисел по НОД и НОК

Если НОД(a,b) = g и НОК(a,b) = L, то:

a = gx, b = gy, НОД(x,y) = 1
xy = L / g
После этого нужно разложить L / g на пары взаимно простых множителей.
4

Количество делителей

Пусть натуральное число n разложено на простые множители:

n = p₁α₁ · p₂α₂ · ... · pₖαₖ

Тогда количество натуральных делителей числа n равно:

(α₁ + 1)(α₂ + 1)...(αₖ + 1)

Пример

50 = 2¹ · 5²
(1 + 1)(2 + 1) = 6

Делители: 1, 2, 5, 10, 25, 50.

Правило минимальности: чтобы получить наименьшее число, большую степень ставим к меньшему простому числу.

Наименьшее число с 12 делителями

Разложение 12 Кандидат Число
122¹¹2048
6·22⁵·396
4·32³·3²72
3·2·22²·3·560
Ответ: 60. Проверка: 60 = 2²·3·5, поэтому (2+1)(1+1)(1+1)=12.
5

Факториал и простые множители

Факториал:

n! = 1 · 2 · 3 · ... · n

Формула Лежандра

Показатель простого числа p в разложении n! равен:

⌊n / p⌋ + ⌊n / p²⌋ + ⌊n / p³⌋ + ...

Суммируем, пока знаменатель не станет больше числителя.

Пример:
сколько раз 2 входит в 5!?
⌊5/2⌋ + ⌊5/4⌋ = 2 + 1 = 3.
Пример:
показатель 3 в 50!:
⌊50/3⌋ + ⌊50/9⌋ + ⌊50/27⌋ = 16 + 5 + 1 = 22.
!

Типичные ошибки

  1. Забывать условие «цифры различны».
  2. Проверять делимость на 4 по сумме цифр. Правильно: две последние цифры.
  3. Использовать цифру 0, когда сказано «ненулевые цифры».
  4. Путать НОД и НОК.
  5. Забывать, что НОД(a,b)·НОК(a,b) = a·b.
  6. При поиске пар по НОД и НОК забывать условие НОД(x,y)=1.
  7. Путать простые множители и их степени.
  8. Ставить большую степень к большему простому числу при поиске минимального числа.
  9. В формуле Лежандра учитывать только ⌊n/p⌋ и забывать ⌊n/p²⌋, ⌊n/p³⌋.
  10. В методе «оценка плюс пример» давать пример без доказательства оптимальности.
