Тригонометрические уравнения

Интерактивный конспект по базовым уравнениям, формулам сложения, двойному углу, разложению на множители и типичным ошибкам.

МАТЕМАТИКА. НАГЛЯДНО. Артём Александрович Лёвин • для Яны Плиско

1. Идея решения

Тригонометрическое уравнение удобно решать так: сначала преобразовать его к простому виду, а затем применить базовое уравнение для sin или cos.

sin α

Это y-координата точки на единичной окружности.

cos α

Это x-координата точки на единичной окружности.

2π

Полный оборот. Поэтому в ответе появляется целый параметр n ∈ Z.

2. Базовые уравнения

Эти шесть формул — фундамент. Их важно не просто запомнить, а понимать через окружность.

Синус

sin α = 1 ⇒ α = π/2 + 2πn sin α = −1 ⇒ α = −π/2 + 2πn sin α = 0 ⇒ α = πn

Косинус

cos α = 1 ⇒ α = 2πn cos α = −1 ⇒ α = π + 2πn cos α = 0 ⇒ α = π/2 + πn

важно Если вместо α стоит 4x, 10x или другой аргумент, сначала решаем относительно всего аргумента, а потом делим каждое слагаемое.

3. Формулы, которые нужно узнавать

Формулы работают в обе стороны: можно раскрывать, а можно сворачивать выражение.

Сложение и разность

sin(α + β) = sinα·cosβ + cosα·sinβ sin(α − β) = sinα·cosβ − cosα·sinβ cos(α − β) = cosα·cosβ + sinα·sinβ cos(α + β) = cosα·cosβ − sinα·sinβ

Двойной угол и тождество

sin 2α = 2sinα·cosα cos 2α = cos²α − sin²α sin²α + cos²α = 1

подсказка Если видите cosA·cosB + sinA·sinB, думайте о cos(A − B).

4. Алгоритм решения

  1. Перенесите всё в одну сторону, чтобы справа был ноль.
  2. Проверьте, можно ли вынести общий множитель.
  3. Проверьте формулы сокращённого умножения и тригонометрические формулы.
  4. Если получилось произведение, приравняйте к нулю каждый множитель.
  5. Сведите к простым уравнениям вида sinα = a или cosα = a.
  6. Аккуратно разделите на коэффициент при x и допишите n ∈ Z.

5. Пошаговый пример

Разберём пример из чек-листа: выражение сначала сворачивается по формуле, затем решается базовое уравнение.

1 − cos3x·cos2x = sin3x·sin2x
Шаг 1. Переносим всё влево:
1 − cos3x·cos2x − sin3x·sin2x = 0
Шаг 2. Группируем тригонометрическую часть:
1 − (cos3x·cos2x + sin3x·sin2x) = 0
Шаг 3. Узнаём формулу cos(A − B):
cos3x·cos2x + sin3x·sin2x = cos(3x − 2x) = cosx
Шаг 4. Получаем простое уравнение:
1 − cosx = 0 ⇒ cosx = 1
Шаг 5. Записываем ответ:
x = 2πn, n ∈ Z

6. Типичные ошибки

  • Забыть n ∈ Z. Без этого ответ неполный.
  • Путать πn и 2πn. Например, cosα = 0 имеет шаг π, а cosα = 1 — шаг 2π.
  • Делить только первое слагаемое. Из 4x = π/2 + 2πn получается x = π/8 + πn/2.
  • Не узнавать формулу справа налево. Именно это часто мешает увидеть короткое решение.
  • Делить на выражение с переменной. Так можно потерять корни, если выражение равно нулю.

Интерактивная окружность

Переключайте уравнение и смотрите, какие точки окружности дают нужное значение.

α = π/2 + 2πn, n ∈ Z

Памятка

sin смотрим на вертикаль y.

cos смотрим на горизонталь x.

n ∈ Z означает любое целое число: ..., −2, −1, 0, 1, 2, ...
