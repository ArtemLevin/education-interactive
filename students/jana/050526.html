Чек-лист:
тригонометрические уравнения

Формулы двойного угла, формулы сложения, вынесение, группировка и замены.

Главная цель:
привести уравнение к одному углу и по возможности к одной функции, затем разложить на множители.
Формулы Алгоритм Методы Простейшие Ошибки
1

Ключевые формулы

Формулы двойного угла

  • sin 2x = 2 sin x cos x
  • cos 2x = cos2x − sin2x
  • cos 2x = 2cos2x − 1
  • cos 2x = 1 − 2sin2x
Выбор формулы
много sin x → берём cos 2x = 1 − 2sin2x;
много cos x → берём cos 2x = 2cos2x − 1.

Формулы сложения

  • cos(α + β) = cos α cos β − sin α sin β
  • sin(α + β) = sin α cos β + cos α sin β
Пример: cos(3π/2 + 2x) = sin 2x
2

Алгоритм решения

  1. Перенесите всё в одну сторону: левая часть = 0.
  2. Сделайте углы одинаковыми: раскройте 2x, сумму углов и т. п.
  3. Сделайте функции одинаковыми, если это возможно.
  4. Найдите общий множитель и вынесите его за скобки.
  5. Разбейте произведение: A(x)B(x)=0 ⇒ A(x)=0 или B(x)=0.
  6. Решите простейшие тригонометрические уравнения.
  7. При замене t = sin x или t = cos x проверяйте −1 ≤ t ≤ 1.
  8. Запишите ответ полными семействами корней, n ∈ ℤ.
3

Приёмы и методы

  • Вынесение общего множителя sin 2x + √3 sin x = 0
    ⇒ sin x(2cos x + √3) = 0
  • Формула сложения cos(3π/2 + 2x) = cos x
    ⇒ sin 2x − cos x = 0
  • Замена через одну функцию cos 2x + sin x = 0
    ⇒ 1 − 2sin2x + sin x = 0
  • Группировка и двойное вынесение 2sin x cos x + √2sin x − 2cos x − √2 = 0
    ⇒ (2cos x + √2)(sin x − 1) = 0
  • Степени и основное тождество sin2x + cos2x = 1
    sin2x = 1 − cos2x
4

Простейшие уравнения

Уравнение Ответ
sin x = 0 x = πn, n ∈ ℤ
cos x = 0 x = π/2 + πn, n ∈ ℤ
sin x = 1 x = π/2 + 2πn, n ∈ ℤ
cos x = 1 x = 2πn, n ∈ ℤ
cos x = −1 x = π + 2πn, n ∈ ℤ

Табличные значения

sin x = 1/2 x = π/6 + 2πn или x = 5π/6 + 2πn
sin x = −1/2 x = −π/6 + 2πn или x = 7π/6 + 2πn
cos x = 1/2 x = ±π/3 + 2πn
cos x = −√3/2 x = 5π/6 + 2πn или x = 7π/6 + 2πn
!

Типичные ошибки

  • Сокращают на sin x или cos x и теряют корни. Правильно: выносить множитель, а не делить на него.
  • Выбирают не ту формулу для cos 2x. Ориентируйтесь на то, какую функцию нужно оставить.
  • Забывают область значений. Уравнения sin x = 2 и cos x = −3 не имеют решений.
  • Теряют знак при группировке. Минус перед скобкой меняет все знаки внутри.
  • Смешивают параметры. Используйте n или k, но обязательно указывайте принадлежность ℤ.
✓

Короткая памятка

  • Привести к одному углу и одной функции.
  • Использовать формулы двойного угла и сложения.
  • Выносить общий множитель, а не делить на него.
  • Группировать, если в уравнении четыре слагаемых.
  • Разбивать произведение на простые уравнения.
  • Проверять область значений тригонометрических функций.
  • Записывать полный ответ семействами корней.
