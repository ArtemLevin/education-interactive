Сначала ОДЗ

Если в уравнении есть логарифм или дробь, решение начинается с ограничений, а не с вычислений.

1
Главная идея: найденный корень обязан не только решать преобразованное уравнение, но и быть допустимым в исходной записи.
logab существует ⇔ b > 0, a > 0, a ≠ 1
Если есть A(x)B(x), то B(x) ≠ 0
Пример:
log3(2cos x) требует 2cos x > 0, то есть cos x > 0.
Пример:
log31(√2cos x) в знаменателе требует одновременно √2cos x > 0 и log31(√2cos x) ≠ 0.
Покажи алгоритм
  1. Найдите логарифмы: подлогарифмическое выражение должно быть положительным.
  2. Найдите дроби: знаменатель не должен быть нулём.
  3. Если ограничение можно упростить, упростите.
  4. В конце обязательно отберите корни.
Мини-вывод: ОДЗ — это фильтр, который нельзя пропускать.

Логарифм убираем аккуратно

Чтобы перейти от логарифмического уравнения к обычному, используйте определение логарифма.

2
Главная идея: logaf(x)=c означает, что f(x)=ac. Но этот переход выполняется вместе с условием f(x)>0.
logaf(x) = c → f(x) = ac
log2(cos x + sin 2x + 8) = 3
cos x + sin 2x + 8 = 23 = 8
cos x + sin 2x = 0
Если после перехода подлогарифмическое выражение равно положительному числу, то его положительность выполнена автоматически.
Покажи объяснение

В выражении log2(cos x + sin 2x + 8)=3 подлогарифмическое выражение после перехода равно 8. Поэтому оно точно положительно, и отдельное решение этого ограничения не требуется.

Мини-вывод: логарифм — это вопрос «в какую степень возвести основание?».

Дробь равна нулю

Дробное уравнение решается через числитель, но знаменатель всё равно должен быть допустимым.

3
Главная идея: дробь равна нулю, когда числитель равен нулю, а знаменатель не равен нулю.
A(x)B(x) = 0 ⇔ A(x)=0 и B(x)≠0
tg x + √3log31(√2cos x) = 0
tg x + √3 = 0
log31(√2cos x) ≠ 0
Для знаменателя нужно не только log31(√2cos x) ≠ 0, но и √2cos x > 0. Из неравенства log31(√2cos x) ≠ 0 следует:
√2cos x ≠ 1, то есть cos x ≠ √2 / 2
Покажи алгоритм
  1. Запишите условия существования всех выражений.
  2. Запишите условие знаменателя: B(x)≠0.
  3. Решайте A(x)=0.
  4. Проверьте найденные корни по всем ограничениям.
Мини-вывод: знаменатель не решает уравнение, но может выкинуть корень.

Разные углы надо привести

Если в уравнении есть x и 2x, нельзя просто «убрать двойку». Нужна формула двойного угла.

4
Главная идея: тригонометрические уравнения удобно решать, когда углы одинаковые.
sin 2x = 2sin x cos x
cos 2x = 1 − 2sin2x = 2cos2x − 1
cos x + sin 2x = 0
cos x + 2sin x cos x = 0
cos x(1 + 2sin x) = 0
Покажи объяснение

Переход от sin 2x к sin x без формулы — грубая ошибка. Сначала применяем формулу двойного угла, затем выносим общий множитель.

Мини-вывод: разные углы — сигнал применить формулы тригонометрии.

Вынесение общего множителя

Если в выражении есть общий множитель, сначала попробуйте вынести его за скобки.

5
Главная идея: вынесение общего множителя часто превращает длинное выражение в простое произведение.
3sin x − 4sin3x = sin x(3 − 4sin2x)
3sin x − 4sin3xsin x = 1
sin x(3 − 4sin2x)sin x = 1
Сокращение на sin x допустимо только там, где sin x ≠ 0. Если sin x стоит в знаменателе исходной дроби, это условие уже входит в ОДЗ.
Покажи алгоритм
  1. Посмотрите, есть ли общий множитель.
  2. Вынесите его за скобки.
  3. Проверьте, не сокращаете ли Вы на выражение, которое может быть нулём.
  4. Решите оставшееся уравнение.
Мини-вывод: сначала ищем общий множитель, потом усложняем решение.

Замена переменной

Если одно и то же логарифмическое выражение повторяется, задача часто превращается в квадратное уравнение.

6
Главная идея: повторяющийся фрагмент заменяем буквой t.
2log32(2cos x) − 5log3(2cos x) + 2 = 0
t = log3(2cos x)
2t2 − 5t + 2 = 0
После решения квадратного уравнения возвращаемся к x. Например, t=1/2 даёт:
log3(2cos x)=1/2
2cos x=31/2=√3
cos x=√3/2
Покажи алгоритм
  1. Найдите повторяющееся выражение.
  2. Обозначьте его через t.
  3. Решите уравнение относительно t.
  4. Сделайте обратную подстановку.
  5. Отберите корни по ОДЗ.
Мини-вывод: замена сокращает длинную задачу до знакомой алгебры.

Не путайте квадраты у логарифма

Положение квадрата полностью меняет смысл записи.

7
Главная идея: смотрите, над чем именно стоит степень: над логарифмом, аргументом или основанием.
log32(2cos x) = (log3(2cos x))2
log3((2cos x)2) = 2log3|2cos x|
log32(2cos x) = 12log3(2cos x)
Покажи объяснение

В записи log32(2cos x) квадрат относится ко всему логарифму. Его нельзя вынести перед логарифмом как степень аргумента.

Мини-вывод: маленький верхний индекс может изменить весь способ решения.

Отбор корней

Найти серии корней — ещё не финал. Их нужно совместить с ОДЗ и выколотыми точками.

8
Главная идея: после решения смотрим, какие точки реально попали в допустимую область.
cos x > 0 ⇒ правая полуплоскость окружности
sin x ≠ 0 ⇒ x ≠ πn
cos x ≠ √2/2 ⇒ x ≠ ±π/4 + 2πn
Например, если из уравнения вышло x = −π/3 + πn, но допустима только правая полуплоскость, остаётся серия:
x = −π/3 + 2πn, n ∈ ℤ
Покажи алгоритм
  1. Отметьте ограничения на окружности.
  2. Отметьте найденные серии корней.
  3. Оставьте только те точки, которые не нарушают ОДЗ.
  4. Если подходит через одну точку, период часто меняется с π на 2π.
Мини-вывод: отбор корней — место, где чаще всего теряются баллы.

Разбор ошибок

Ключевые ошибки темы в формате «ответ → ошибка → правильная мысль».

9
Неверно:
−4sin2x = −2 ⇒ sin2x = −1/2
Правильно:
sin2x = (−2)/(−4) = 1/2
Неверно:
cos 2x = 2 ⇒ искать arccos 2
Правильно:
решений нет, потому что cos t ∈ [−1; 1]
Неверно:
sin 2x заменить на sin x без формулы
Правильно:
sin 2x = 2sin x cos x
Неверно:
log32(2cos x) вынести как степень аргумента
Правильно:
log32(2cos x) = (log3(2cos x))2
Покажи правильный алгоритм
  1. Сначала ограничения.
  2. Потом корректные формулы.
  3. Затем алгебра без потери знаков.
  4. В конце отбор по ОДЗ.
Мини-вывод: большинство ошибок здесь не вычислительные, а логические.
