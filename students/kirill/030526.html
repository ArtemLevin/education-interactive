1 / база

Координаты точки

Точка записывается как пара чисел:

A(x; y)
  • xпервая координата: движение по горизонтали.
  • yвторая координата: движение по вертикали.
  • 0начало координат: O(0; 0).
2 / навигация

Правило знаков

x > 0
идём вправо
x < 0
идём влево
y > 0
идём вверх
y < 0
идём вниз

Сначала откладывайте x, потом y. Не наоборот.

3 / построение

Как построить ломаную

Ломаная MNAP строится строго в указанном порядке:

M → N → A → P
  • 1поставьте все точки на координатной плоскости;
  • 2подпишите точки;
  • 3соедините соседние точки отрезками по порядку.
4 / общая точка

Точки пересечения

Точка пересечения лежит сразу на двух линиях.

Q ∈ l₁ Q ∈ l₂
  • Oxесли точка на оси Ox, то y = 0;
  • Oyесли точка на оси Oy, то x = 0;
  • ≈если точка не попала в узел сетки, координаты можно оценить приблизительно.
5 / отражение

Симметрия

Запомните, какой знак меняется.

  • O(x; y) → (−x; −y) относительно начала координат.
  • Oy(x; y) → (−x; y) относительно оси ординат.
  • Ox(x; y) → (x; −y) относительно оси абсцисс.
6 / контроль

Типичные ошибки

  • !путают x и y местами;
  • !забывают знак минус;
  • !соединяют точки не по порядку;
  • ✓обязательно подписывайте точки.
