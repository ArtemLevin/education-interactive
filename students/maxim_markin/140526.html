Сначала ищите структуру, а не считайте в лоб

В задачах занятия главный выигрыш дают не длинные вычисления, а распознавание формы: квадрат, общая скобка, одинаковый показатель, сумма синусов или кредитная таблица.

✦ Главная идея

Разбейте выражение на роли: что влияет на знак, что является квадратом, где есть ОДЗ, что можно заменить, где стоит применить формулу суммы.

повторяется фрагмент → сгруппировать / вынести / заменить
Покажи алгоритм
  1. Запишите ОДЗ до сокращений.
  2. Найдите квадраты и множители, не влияющие на знак.
  3. Вынесите повторяющиеся выражения.
  4. Сделайте замену, если один и тот же блок повторяется несколько раз.
  5. Вернитесь к исходной переменной и проверьте ограничения.

2 тригонометрия

Сумма синусов раскрывается только по формуле

Нельзя раскладывать синус суммы как сумму синусов. Нужно раскрывать каждый угол отдельно и собирать коэффициенты при sin x и cos x.

✦ Формулы
sin(α + β) = sin α · cos β + cos α · sin β
cos(α + β) = cos α · cos β − sin α · sin β
✦ Пример раскрытия
sin(x + π/6) = (√3/2)sin x + (1/2)cos x
Покажи объяснение

После раскрытия нескольких синусов обычно появляются похожие коэффициенты. Их нужно сгруппировать: отдельно всё с sin x, отдельно всё с cos x.

Мини-вывод: сначала раскрыть углы, потом группировать.

Не перепутайте

sin(x + a) ≠ sin x + sin a
cos(x + a) ≠ cos x + cos a

Это одна из самых частых ошибок в тригонометрии.

3 однородность

Если вышло A·sin x + B·cos x = 0

Такое уравнение часто сводится к тангенсу. Но перед делением на cos x нужно проверить, не теряется ли решение.

✦ Алгоритм
  1. Проверьте случай cos x = 0.
  2. Если он не подходит, делите на cos x.
  3. Получайте A·tg x + B = 0.
A sin x + B cos x = 0 → A tg x + B = 0
✦ Учебный пример
sin x + cos x = 0 → tg x = −1 → x = −π/4 + πn
Покажи объяснение

Если cos x = 0, то исходное уравнение sin x + cos x = 0 превращается в sin x = 0, что невозможно одновременно с cos x = 0. Поэтому в этом примере деление на cos x не теряет решений.

Мини-вывод: делить можно только после проверки нулевого случая.

4 знак

Квадрат влияет не на знак, а на точки

В неравенствах квадратные множители часто не меняют знак, но могут дать ноль числителя. Знаменатель-квадрат тоже не меняет знак, но его нули запрещены.

✦ Главная идея
(x − 1)2 ≥ 0
знаменатель ≠ 0
✦ Пример
((x + 1)(x − 1)2) / (2x² − 8)2 ≤ 0

На знак влияет x + 1. Точка x = 1 подходит как ноль числителя. Точки x = ±√3 запрещены, потому что обнуляют знаменатель.

Покажи алгоритм
  1. Найдите нули знаменателя и исключите их.
  2. Отметьте квадратные множители числителя как неотрицательные.
  3. Решите неравенство по множителям, реально влияющим на знак.
  4. Добавьте нули числителя, если неравенство нестрогое.
Мини-вывод: квадрат — не повод забывать про нули.

Мини-ось

Закрашенная точка — включаем. Пустая — исключаем.

5 степени

Показательная замена надёжнее «быстрого перехода»

Если несколько раз встречается один и тот же показатель, лучше ввести замену. Это снижает риск потерять ограничения.

✦ Главная замена
t = 5x/(x+3),   t > 0,   x ≠ −3
✦ Полезное разложение показателя
(2x + 3)/(x + 3) = x/(x + 3) + 1
5(2x+3)/(x+3) = 5 · 5x/(x+3) = 5t
Покажи алгоритм
  1. Запишите ОДЗ знаменателя показателя.
  2. Введите t = aповторяющийся показатель, обязательно t > 0.
  3. Решите обычное неравенство относительно t.
  4. Вернитесь к x и решите полученные дробные неравенства.
Мини-вывод: замена превращает показательную задачу в обычную алгебру.

Пример результата

t² − 6t + 5 ≥ 0 → (t − 1)(t − 5) ≥ 0
0 < t ≤ 1 или t ≥ 5

Условие t > 0 обязательно.

6 экономика

Дифференцированный кредит: долг уменьшается равными частями

В такой схеме каждый месяц гасится одинаковая часть основного долга, а проценты начисляются на текущий остаток.

✦ Обозначения
S — кредит n — месяцев p = r / 100
основной долг каждый месяц: S/n
платёж k-го месяца: Ak = S/n + pS·(n − k + 1)/n
сумма выплат за все n месяцев: T = S + pS·(n + 1)/2
Покажи объяснение

Остатки долга образуют арифметическую последовательность: S, S·(n−1)/n, ..., S/n. Поэтому сумма процентов считается через сумму 1 + 2 + ... + n.

Мини-вывод: проценты убывают, потому что остаток долга уменьшается.

Формула ставки

p = 2(T − S) / (S(n + 1))
r = 100p

Не путайте p и r: p — доля, r — процент.

7 ошибки

Разбор ошибок: неверный ход → ошибка → как правильно

Ниже — ошибки, которые особенно легко получить в этих типах задач.

Неверный ход:
sin(x + π/6) = sin x + sin(π/6)
Ошибка: такой формулы нет.
Правильно:
sin(x + π/6) = sin x·cos(π/6) + cos x·sin(π/6)
Неверный ход: исключить квадратный множитель и забыть его ноль.
Ошибка: в нестрогом неравенстве ноль числителя может входить в ответ.
Правильно: квадрат не меняет знак, но его нули проверяются отдельно.
Покажи короткий правильный алгоритм
  1. Формулы — только канонические, без «похожих» сокращений.
  2. Перед сокращением проверяйте нули множителей.
  3. Перед ответом сверяйте ОДЗ.
Мини-вывод: большинство ошибок — не вычислительные, а логические.

Ответы спрятаны. Сначала попробуйте ответить устно, затем раскройте проверку.

1) Почему нельзя писать sin(x + a) = sin x + sin a?

Потому что для синуса суммы действует формула: sin(x + a) = sin x·cos a + cos x·sin a.

2) Что обязательно сделать перед сокращением дроби?

Проверить ОДЗ и понять, не может ли сокращаемый множитель быть равен нулю.

3) Что означает условие t > 0 при замене t = 5x/(x+3)?

Любая степень числа 5 даёт только положительное значение, поэтому t не может быть нулём или отрицательным.

4) Почему квадрат в знаменателе не влияет на знак, но важен?

Он положителен всюду, где определён, но его нули запрещены, потому что знаменатель не может быть равен нулю.

5) Какая сумма нужна в дифференцированной схеме?

Сумма 1 + 2 + ... + n = n(n + 1)/2, потому что проценты начисляются на убывающие остатки долга.
