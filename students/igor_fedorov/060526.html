1 Размерности и единицы

Единицу физической величины удобно получать из формулы: подставляем единицы величин справа и упрощаем.

Давление

p = F / S

Единица: Н/м² = Па.

Для жидкости также: p = ρgh

Жёсткость пружины

k = Fупр / |Δx|

Единица: Н/м.

Абсолютная влажность

ρпара = mпара / V

Единица: кг/м³.

Проверка

  • Не угадывайте единицу.
  • Сначала запишите формулу.
  • Сократите единицы как дроби.

2 Путь и перемещение

Путь

Путь — длина траектории. Это скаляр.

l ≥ 0

Перемещение

Перемещение — вектор от начального положения к конечному.

sx = xкон − xнач
|sx| = |xкон − xнач|
Если тело вернулось в начальную точку, путь может быть большим, но модуль перемещения равен нулю.

3 Сообщающиеся сосуды

В неподвижных несмешивающихся жидкостях давления сравнивают на одном горизонтальном уровне.

Баланс давлений

p₁ = p₂
ρ₁gh₁ = ρ₂gh₂
ρ₂ / ρ₁ = h₁ / h₂

Смысл

Если столб первой жидкости выше, то её плотность меньше.

Большая высота ↔ меньшая плотность.

4 Тепловые процессы

Тепловой баланс

Q₁ + Q₂ + ... + Qₙ = 0
Qотдано = Qполучено

Q > 0 — тело получает теплоту.
Q < 0 — тело отдаёт теплоту.

Формулы

  • Нагревание/охлаждение: Q = cm(t₂ − t₁)
  • Плавление: Q = λm
  • Кристаллизация: Q = −λm
  • Парообразование: Q = rm
  • Конденсация: Q = −rm
На горизонтальном участке графика температура постоянна: формулу Q = cmΔt использовать нельзя.

Электронагрев

P = U² / R
A = (U² / R)τ
Qполезн = ηA

Если вода выкипает

Сначала вода нагревается до 100 °C, потом энергия идёт на парообразование.

η(U²/R)τ = cm(100 − t₀) + rmпара

Корректный учебный график нагревания льда, плавления, нагревания воды, кипения и дальнейшего нагревания пара. Горизонтальные участки — фазовые переходы.

! Ошибки

  • Минуты забывают перевести в секунды.
  • Путают λ и r.
  • Складывают участки графика x(t), когда нужно перемещение.
  • Не проверяют, хватило ли энергии на кипение.
