Главная стратегия

Сложную запись переводим в знакомую форму.

Главная идея

В алгебре Вы ищете полный квадрат. В геометрии — удобный треугольник. В обоих случаях решение начинается не с вычислений, а с распознавания структуры.

Под корнем:
m + 2√n → (a + b)2
В геометрии:
параллограмм / ромб → треугольники
Мини-вывод: сначала структура, потом формула.
Покажи объяснение

Выражение 4 + 2√3 похоже на результат раскрытия квадрата: a2 + 2ab + b2. А диагональ параллелограмма создаёт треугольник, где можно применить теорему синусов.

2

Метод неопределённых коэффициентов

Как представить m + 2√n в виде квадрата суммы.

Алгоритм

  1. Пишите: m + 2√n = (a + b)2.
  2. Раскрываете квадрат.
  3. Сравниваете рациональную и иррациональную части.
  4. Находите один подходящий набор a и b.
(a + b)2 = a2 + 2ab + b2
Поэтому: a2 + b2 = m, 2ab = 2√n.
Для упрощения корня достаточно одной корректной пары a и b.
Покажи алгоритм через замену
  1. Из ab = √n выразите a = √n / b, где b ≠ 0.
  2. Подставьте в a2 + b2 = m.
  3. Сделайте замену t = b2, где t > 0.
  4. Решите уравнение относительно t и вернитесь к a, b.
3

Корень из квадрата: не теряем модуль

Квадрат и корень сокращаются только через модуль.

√(u2) = |u|
Значит: √((a + b)2) = |a + b|.

Пример 1

4 + 2√3 = (√3 + 1)2, потому что (√3)2 + 12 = 4 и 2 · √3 · 1 = 2√3.

√(4 + 2√3) = |√3 + 1| = √3 + 1.

Пример 2

29 + 12√5 = (2√5 + 3)2, поэтому √(29 + 12√5) = 2√5 + 3.

Покажи объяснение

Модуль можно раскрыть только после проверки знака. Здесь √3 + 1 и 2√5 + 3 положительны, поэтому модуль раскрывается без изменения выражения.

4

Квадрат разности

Если перед корнем стоит минус, используем (a − b)2.

Главная идея

Выражение вида m − 2√n можно представить как квадрат разности: (a − b)2 = a2 − 2ab + b2.

m − 2√n = (a − b)2
Тогда: a2 + b2 = m, 2ab = 2√n.

Пример

4 − 2√3 = (√3 − 1)2.

√(4 − 2√3) = |√3 − 1| = √3 − 1.
Покажи объяснение

Система для a и b остаётся почти той же, меняется только знак между a и b в итоговой скобке. После извлечения корня модуль всё равно обязателен.

5

Связь с тригонометрией

Иррациональный дискриминант можно упростить тем же способом.

Главная идея

После замены t = tg x иногда получается квадратное уравнение. Если √D выглядит сложно, попробуйте представить D как полный квадрат.

Если D = 4 + 2√3, то √D = √3 + 1.
Если D = 4 − 2√3, то √D = √3 − 1.
tg x = 1 → x = π/4 + πn, n ∈ Z.
tg x = −√3 → x = −π/3 + πn, n ∈ Z.
Важно: у тангенса период π, а не 2π.
Покажи алгоритм
  1. Сделайте замену t = tg x.
  2. Решите квадратное уравнение относительно t.
  3. Если дискриминант содержит корни, выделите полный квадрат.
  4. Вернитесь к уравнениям tg x = t.

Параллелограмм: диагональ даёт треугольник

В задачах на отношение сторон часто работает теорема синусов.

Главная идея

Если диагональ делит угол параллелограмма, смотрите на треугольник, где лежат нужные стороны. Углы переносим через параллельность сторон.

Теорема синусов:
asin A = bsin B

Пример-скелет

Если напротив AD лежит угол 30°, а напротив CD — угол 45°, то:

AD / CD = sin 30° / sin 45° = 1 / √2.
Покажи объяснение

В параллелограмме противоположные стороны параллельны, поэтому диагональ создаёт равные накрест лежащие углы. После этого задача становится обычной задачей про треугольник.

7

Квадрат внутри прямоугольного треугольника

Ключ — подобие маленьких прямоугольных треугольников.

Ситуация

Две вершины квадрата лежат на гипотенузе, две другие — на катетах. Пусть внешние отрезки гипотенузы равны a и b, а сторона квадрата равна x.

Из подобия: x / a = b / x.
Значит: x2 = ab.
Площадь квадрата S = x2 = ab.
Покажи объяснение

Малые треугольники по краям квадрата подобны: у них есть прямой угол и равные острые углы. Стороны сопоставляются по углам, напротив которых они лежат.

Ромб: расстояние от центра до стороны

Самый надёжный путь — площадь и высота.

Что помнить

  • Все стороны ромба равны.
  • Диагонали ромба перпендикулярны.
  • Диагонали ромба делят углы пополам.
  • Расстояние от точки до прямой — перпендикуляр.
S = a · h, а также S = a2 · sin α.

Пример

Если сторона ромба равна 4, а острый угол равен 30°, то S = 42 · sin 30° = 8. Высота h = 8 / 4 = 2. Расстояние от центра до стороны равно h / 2 = 1.

Покажи объяснение

Центр ромба находится посередине между параллельными сторонами. Поэтому расстояние от центра до одной из этих сторон равно половине высоты ромба.

Разбор ошибок

Неверный ход → ошибка → правильная мысль.

Ошибка 1

Неверно: √(u2) = u.

Правильно: √(u2) = |u|.

Суть: арифметический корень неотрицателен.

Ошибка 2

Неверно: из 2ab = 12√5 получить ab = 12√5.

Правильно: ab = 6√5.

Суть: коэффициент 2 нужно разделить.

Ошибка 3

Неверно: tg x = a → x = arctg a + 2πn.

Правильно: x = arctg a + πn.

Суть: период тангенса равен π.

Ошибка 4

Неверно: в подобных треугольниках сравнивать стороны «по рисунку».

Правильно: сопоставлять стороны по равным углам.

Суть: рисунок помогает, но не доказывает соответствие.

Покажи правильный алгоритм
  1. Определите структуру: квадрат, подобие, площадь, теорема синусов.
  2. Запишите формулу полностью.
  3. Проверьте знак, модуль, период или соответствие сторон.
  4. Только после этого упрощайте ответ.

Ловушки темы

Короткие предупреждения, которые сохраняют баллы.

Не забывайте модуль: √(u²) = |u|.
В (a + b)² средний член — именно 2ab.
При замене t = b² обязательно t > 0.
У tg x период π, не 2π.
В геометрии сначала ищите треугольник.
Стороны в подобии сопоставляйте по углам.
Расстояние до прямой — только перпендикуляр.
Мини-вывод: чаще всего ошибка прячется в одном коротком переходе.
Покажи объяснение

В этой теме важно не только знать формулы, но и аккуратно выполнять малые проверки: знак под модулем, область замены, период тангенса, соответствие сторон в подобных треугольниках.

Повтори за 30 секунд

Пять быстрых вопросов для самопроверки.

1. Чему равно √(u²)?

|u|. Без проверки знака писать просто u нельзя.

2. Что сравниваем в m + 2√n = (a + b)²?

Рациональную часть: a² + b² = m. Иррациональную часть: 2ab = 2√n.

3. Какой период у уравнения tg x = a?

π. Общий вид: x = arctg a + πn, n ∈ Z.

4. Что обычно делать с параллелограммом?

Провести диагональ и перейти к треугольнику.

5. Как найти расстояние от центра ромба до стороны через высоту?

Найти высоту ромба h, затем взять h / 2.

Если уверенно ответили на 4 из 5 — база темы собрана.

Опорные формулы и правила

Нажмите, чтобы открыть скрытую часть.

Квадрат суммы

(a + b)² = a² + 2ab + b²

Квадрат разности

(a − b)² = a² − 2ab + b²

Корень из квадрата

√(u²) = |u|

Теорема синусов

a / sin A = b / sin B

Площадь ромба

S = a² · sin α = a · h

Квадрат в прямоугольном треугольнике

S = x² = ab

Тангенс

tg x = a → x = arctg a + πn

Покажи объяснение

Эти правила покрывают основные ходы занятия: корни, тригонометрическую замену, параллелограмм, ромб и квадрат внутри прямоугольного треугольника.
