Чтение строк

Безопасный шаблон чтения файла построчно.

Коротко

Безопасное чтение файла построчно почти всегда делается через один устойчивый шаблон.

read-lines.shcanonical
while IFS= read -r line; do
    echo "$line"
done < "$file"

Глубже: почему именно такой шаблон

IFS= защищает пробелы в начале и конце строки. read -r запрещает специальную обработку обратных слэшей. Перенаправление < "$file" подаёт файл на вход циклу без лишнего cat.

IFS=

Не даёт shell автоматически обрезать пробельные символы.

read -r

Сохраняет обратные слэши как обычные символы.

done < "$file"

Подключает файл как stdin для всего цикла.

"$line"

Сохраняет строку одним аргументом.

Типичная ошибка: for + cat

bad.shdo not use
for line in $(cat "$file"); do
    echo "$line"
done

Такой код ломает строки по пробелам и теряет структуру файла. Для файлов со строками почти всегда используйте while IFS= read -r.
