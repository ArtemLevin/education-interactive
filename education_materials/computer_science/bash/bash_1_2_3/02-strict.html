set -euo pipefail

Строгий режим как базовая защита от тихих ошибок.

Глубже: строгий режим не магия, а страховка

set -euo pipefail не делает скрипт «безошибочным». Он делает ошибки заметнее. Особенно важен pipefail: без него команда слева в пайплайне может упасть незаметно.

-e

Останавливает скрипт при неуспешной команде, но имеет исключения в условиях и логических цепочках.

-u

Ловит опечатки в именах переменных: $VRA вместо $VAR.

pipefail

Не даёт пайплайнам маскировать ошибки предыдущих команд.

Явная обработка

Для ожидаемых ошибок используйте if или cmd || { ... }.

Главная строка безопасности

strict-moderecommended
set -euo pipefail

Что означает

  • -e / errexit: остановка при первом ненулевом коде возврата.
  • -u / nounset: ошибка при обращении к неопределённой переменной.
  • -o pipefail: пайплайн считается упавшим, если внутри упала важная команда.
Исключения для -e: команды внутри if, while, а также связанные через || и &&.

Почему pipefail важен

examplesilent failure
false | true
echo $?

Без pipefail результат может быть 0, хотя первая команда упала. С pipefail ошибка не будет скрыта.
