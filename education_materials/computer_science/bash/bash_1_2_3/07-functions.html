Функции и local

Область видимости, возврат статуса и возврат текста.

Глубже: функция должна быть маленькой и предсказуемой

В Bash переменные глобальны по умолчанию. Поэтому local — не косметика, а защита от скрытых конфликтов.

return в Bash возвращает только числовой статус. Если функция должна «вернуть строку», она печатает её через echo, а вызывающий код забирает результат через $(...).

Правило проектирования: функция либо печатает данные в stdout, либо пишет ошибки в stderr, либо возвращает статус — не смешивайте всё без необходимости.

Шаблон функции

functionlocal scope
my_func() {
    local STATUS="$1"
    local MSG="$2"
    echo "[$STATUS] $MSG"
    return 0
}

Ключевые правила

  • В Bash переменные глобальны по умолчанию.
  • local защищает основной скрипт от случайной перезаписи.
  • return возвращает только код статуса: число от 0 до 255.
  • Чтобы вернуть текст, используйте echo и захват результата.
capturetext result
RESULT="$(my_func OK "Готово")"
