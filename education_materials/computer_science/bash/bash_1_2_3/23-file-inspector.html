Inspector

Мини-проект: анализатор файла или директории.

Мини-проект: file-inspector.sh

Скрипт принимает путь и выводит краткий отчёт: существует ли путь, файл это или директория, можно ли читать/писать.

Требования:
├─ shebang #!/bin/bash
├─ strict mode set -euo pipefail
├─ обязательный аргумент PATH
├─ проверки -e, -f, -d, -r, -w
└─ ошибки в stderr

Ориентир решения

file-inspector.shreference skeleton
#!/bin/bash
set -euo pipefail

PATH_TO_CHECK="${1:?Нужен путь}"

if [[ ! -e "$PATH_TO_CHECK" ]]; then
    echo "Путь не существует: $PATH_TO_CHECK" >&2
    exit 1
fi

if [[ -f "$PATH_TO_CHECK" ]]; then
    echo "type=file"
elif [[ -d "$PATH_TO_CHECK" ]]; then
    echo "type=directory"
else
    echo "type=other"
fi

[[ -r "$PATH_TO_CHECK" ]] && echo "readable=yes" || echo "readable=no"
[[ -w "$PATH_TO_CHECK" ]] && echo "writable=yes" || echo "writable=no"
