Найдите ошибку в каждом фрагменте и запишите исправленный вариант. Проверка ищет ключевые элементы.

Ошибка 1: опасное удаление

bad-delete.shbug
rm -rf $DIR

Ошибка 2: чтение строк через for

bad-read.shbug
for line in $(cat "$file"); do
    echo "$line"
done

Ошибка 3: find без кавычек

bad-find.shbug
find . -type f -name *.txt
