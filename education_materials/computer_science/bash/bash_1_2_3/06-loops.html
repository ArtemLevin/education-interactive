Циклы

Безопасный перебор аргументов и файлов.

Глубже: цикл должен сохранять границы данных

Главная ошибка новичка — написать for x in $@. Это ломает аргументы с пробелами. Форма for x in "$@" сохраняет структуру входа.

nullglob полезен при переборе файлов, потому что пустая директория не должна случайно обрабатываться как файл с именем *.txt.

Перебор аргументов

argssafe
for ITEM in "$@"; do
    echo "Обрабатываю: $ITEM"
done

"$@" сохраняет аргументы отдельными словами. Это важно для строк с пробелами.

Перебор файлов

filesnullglob
shopt -s nullglob
for f in *.txt; do
    echo "Файл: $f"
done
shopt -u nullglob

Если файлов *.txt нет, цикл просто не выполнится.

Без nullglob Bash может передать в цикл буквальный текст *.txt.
