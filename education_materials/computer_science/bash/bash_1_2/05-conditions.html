Условия [[ ... ]]

Современные Bash-тесты, сравнения строк и чисел.

Глубже: условия — это не только if

[[ ... ]] возвращает код статуса: 0 означает «истина», ненулевой код — «ложь». Поэтому условия в Bash построены вокруг exit status, а не вокруг булевых значений как в Python или JavaScript.

Строковые и числовые сравнения различаются: == сравнивает строки, а -eq, -gt, -lt сравнивают числа.

Хороший стиль: сначала явно проверить пустоту входа, затем сравнивать значение с допустимыми вариантами.

Базовый if

ifbash
if [[ -z "$VAR" ]]; then
    echo "Пусто"
elif [[ "$VAR" == "POST" ]]; then
    echo "Метод POST"
else
    echo "Другое значение"
fi

Почему [[ ... ]]

[[ ... ]] — встроенный синтаксис Bash. Он удобнее старого [ ... ] и безопаснее при работе с пустыми строками, &&, || и regex.

Операторы

  • -z — строка пустая.
  • -n — строка не пустая.
  • -eq -ne -gt -ge -lt -le — числовые сравнения.
  • == != — строковые сравнения.
Внутри [[ ]] пишите &&, ||, !. Не используйте устаревшие -a и -o.
