Команда find

Веб-сайт по макету mindmap: все ключевые идеи команды find собраны в виде рукописной карты с цветными ветками, быстрыми примерами и практической логикой.

Открыть карту Шпаргалка

Главная формула

Сначала указываем место, потом условия, затем действие.

$ find [путь] [условия] [действие]
# сначала проверить результат
$ find . -name "*.tmp"
# потом удалять
$ find . -name "*.tmp" -delete

1Суть
  • поиск файлов и папок
  • рекурсивный обход каталогов
  • можно искать и сразу выполнять действие

  • -type f / -type d / -type l

5Логика условий
  • И — по умолчанию
  • ИЛИ — -o
  • НЕ — ! / -not
  • скобки: \( ... \)
пример:
-type f \( -name "*.jpg" -o -name "*.png" \)
