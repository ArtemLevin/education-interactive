Краткая теория

1. Углы в треугольнике

  • Сумма углов треугольника равна 180°.
  • В равнобедренном треугольнике углы при основании равны.
  • Биссектриса делит угол пополам.
  • Для инцентра: ∠AOC = 90° + ∠B / 2.

2. Окружность

  • Вписанный угол равен половине дуги, на которую опирается.
  • Противоположные углы вписанного четырёхугольника дают 180°.
  • Угол между двумя секущими равен половине разности дуг.
  • Хорда: a = 2R · sin(φ/2).

3. Четырёхугольники

  • Параллелограмм: S = ah.
  • Ромб: S = d₁d₂ / 2.
  • Описанный четырёхугольник: AB + CD = BC + AD.
  • Трапеция: m = (a + b) / 2.
