Классы веществ

Задача: быстро распознать соль, оксид, кислоту или основание по формуле.

Если видите:
  • металл или NH4+ + кислотный остаток → соль;
  • H + кислотный остаток → кислота;
  • элемент + O → оксид;
  • металл + OH → основание или амфотерный гидроксид.
Покажи алгоритм
  1. Найдите металл, H, O, OH-группу и кислотный остаток.
  2. Отделите кислоты от солей: у кислот H стоит как замещаемый атом.
  3. Проверьте, есть ли H в кислотном остатке соли.
  4. Сделайте вывод о классе вещества.
Важно!
Средняя соль не содержит H в кислотном остатке. Кислая соль содержит H в кислотном остатке.

NH4NO3 — средняя соль
CrO3 — кислотный оксид
H2SO3 — двухосновная кислота

Серная кислота

Развилка: разбавленная H2SO4 — обычная кислота, горячая концентрированная — сильный окислитель.

Помните:
  • разб. кислота + сульфид → H2S;
  • конц. H2SO4 часто даёт SO2;
  • основный оксид + кислота → соль + вода;
  • с металлами в концентрированной кислоте H2 обычно не выделяется.
Покажи алгоритм выбора продукта
  1. Проверьте: кислота разбавленная или концентрированная.
  2. Для разбавленной кислоты примените обычные кислотные свойства.
  3. Для концентрированной горячей кислоты проверьте ОВР.
  4. Если кислота восстанавливается, частый продукт — SO2.

pH и расчёты по газу

Две базы: сравнивайте среду растворов и аккуратно считайте по коэффициентам.

pH по возрастанию:

NH4Cl < LiNO3 < NH4OH < KOH
кислая → нейтральная → слабощелочная → сильнощелочная

Покажи алгоритм pH
  1. Определите: кислота, основание или соль.
  2. Для соли найдите, чем она образована: сильная/слабая кислота и сильное/слабое основание.
  3. Проверьте гидролиз по катиону или аниону.
  4. Расположите: кислая < нейтральная < щелочная среда.

Ловушки ЕГЭ

Ловушка 1. «С каждым реагентом» ≠ «с одним из реагентов».
Ловушка 2. Конц. H2SO4 — не просто кислота, а окислитель.
